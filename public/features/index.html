Features

What ships today, stated plainly. “Not in this version” is deliberate: those paths need a backend, accounts or a data contract we have not shipped.

01

Available now

Area What it does Status
Canvas & true scale Infinite dotted canvas; every dimension is stored in centimetres and rendered to scale at the current zoom. Available
Boards Place, move and rotate catalogue boards, or create a custom size and finish. Available
Pedals & custom gear Search the catalogue, place pedals, drag, rotate, duplicate and delete; create custom pedals and power supplies. On mobile, the + Pedals and + Boards dock tabs open the picker. Available
Layers Reorder parts within a board so overlaps read correctly. Available
Patch cables Drag jack-to-jack connections, add instrument/amp endpoints, color-code each cable with a fixed patch ink, and read a derived cable schedule. Available
Continuity Check Derived warnings for direction, missing jacks, dangling ends and loops. Warnings never block an edit. Available
Jack correction Move a placed catalogue pedal's jacks on the real footprint, per scene, including top-face jacks; reset at any time. Available
Measure & grid Margin Rule readout, selectable grid step, cm/in toggle and a temporary measure tool. Available
Viewport focus Frame a board or the used area, paginate boards, and lock the camera while editing. Available
Scenes Named scenes with autosave in this browser, a 10-scene cap, and a backup download if storage fails. Available
Export True-scale PNG, plus a print-ready PDF: Fit A4 (default) or Fit Letter at a stated ratio, or True size for exact-cm printing — with a ruler and print-at-100% reference in your chosen cm/in unit. Available
Share links Read-only scene links encoded in the URL hash; recipients can browse, measure and save a copy. Available
Desktop & mobile Responsive chrome with touch-friendly targets, and dark and light themes. Available
02

Not in this version

Area Why it is not here yet Status
Accounts & cloud sync Scenes are local-only today; accounts and cloud saves need a backend and a privacy model. Deferred
Power-supply planner The schema reserves power fields and the info panel shows supply details, but output planning is not built. Deferred
Community submissions Corrections and removal requests run through GitHub issues; there is no upload queue or moderation backend. Deferred
Analytics This build ships no product analytics, tracking cookies or session replay. Deferred
Tiered boards Multiple tiers and risers need height/clearance geometry that is not in the v1 board contract. Deferred
Offline install (PWA) The app works in the browser; installability is planned but not shipped. Deferred
