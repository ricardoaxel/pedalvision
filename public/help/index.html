How to use Pedalvision

One operation per section. Everything is saved locally as you work; no account is required.

01

Start with a board

  1. Choose Add board on the toolbar or the + Boards tab.
  2. Pick a catalogue board, or create a custom size and finish.
  3. Drag the board to move it; drag its handle to rotate it.
  4. Select a board and use Color in its action bar for a colored border; the finish stays as chosen.
02

Add and arrange pedals

  1. Open Add pedal (or the + Pedals tab on mobile), search by brand, model or effect, then place it. The filter chips also include Stereo for pedals whose catalogue spec records stereo capability.
  2. Drag a pedal onto a board to attach it; drag it off to leave it loose.
  3. Select a part to duplicate, rotate, delete or reorder it.
  4. Use Color on a selected part for a slim organization outline; choose Default to clear it.
  5. Add a short personal Label in the info panel (e.g. “always on”). It appears under the name chip and saves, shares and exports.
  6. Select a catalogue pedal to see a few Similar pedals in its info panel — tap one to open the picker already filtered to that effect.
  7. Use Custom for gear the catalogue does not carry.
03

Patch cables and check signal flow

  1. Turn on the patch, then drag from one jack to another.
  2. Select a cable to give it a fixed patch ink, a custom color, or Default from its action bar (a compact picker on phones). Colors save, share and export.
  3. Add instrument and amp endpoints for the ends of the chain.
  4. Open Cables for the derived cable schedule.
  5. Open Continuity to warn about direction, missing jacks, dangling ends or loops. Warnings never block edits.
04

Work at true scale

All geometry is stored in centimetres. The Margin Rule at the bottom shows the visible extent, the grid pitch and a true-length reference at the current zoom.

  • Scroll or pinch to zoom; drag empty canvas to pan.
  • Switch the readout between cm and in.
  • Choose a grid step (1, 2, 5, 10 or 20 cm); it is a precision ceiling, not the drawn pitch.
  • Use Measure to drag a temporary line and read its true length.
05

Correct a jack position

  1. Select a placed catalogue pedal and start Press Proof.
  2. Drag a jack pin to its real position, including the top face.
  3. Set the jack kind if needed, then finish to keep the correction in this scene.
  4. Reset a single jack or all corrections at any time.
06

Save, export and share

  • Scenes autosave in this browser; open Scenes to rename, switch or delete them.
  • Export writes a true-scale PNG or a printable PDF of the selected board or all content.
  • PDF defaults to Fit A4 (Fit Letter when you work in inches): the whole plan on one sheet at a stated scale such as 1:2.3. Choose True size for an exact-cm page (use a large-format printer or a copy shop).
  • Print the PDF at 100% and check the ruler on the sheet; the caption states the scale.
  • Share builds a read-only link. The scene is encoded in the URL hash after #, so only someone with the link can open it.
  • In a shared preview you can browse, measure and save a copy; you cannot edit the sender's scene.
07

Keyboard shortcuts

Key Action
F Frame the selected board or the used area
L Lock or unlock the camera to the pinned board
M Toggle the measure tool
Esc Clear or leave the current canvas mode
⌘/Ctrl Z Undo
⇧ ⌘/Ctrl Z Redo
⌘/Ctrl D Duplicate the selected part
Delete / Backspace Delete the selected part
↑ ↓ ↵ Browse and place in the picker
