# Raw research archive

Brand agents write **only** here:

```text
data/catalog/research/pedals/<brand-slug>/<batch>.json
data/catalog/research/boards/<brand-slug>/<batch>.json
```

- One file = one batch; the folder must match the brand slug.
- Schema: `src/catalog/rawSchema.ts`; contract: `docs/catalog/raw-research-record.md`.
- Raw records keep every verified fact, connector, image candidate and source page — even fields the runtime schema does not show yet.
- A batch PR contains raw records + hosted assets + its task file only. Never edit `data/catalog/{pedals,boards}/**` (mapped), `src/catalog/data/**` (runtime), or `data/catalog/registry.json` (generated).
- Generated by the post-merge build: raw → mapped → runtime. CI builds into a temp dir and validates; it also generates an uncommitted runtime for Playwright.
- Optional fields are opportunistic: capture only what appears during the same base research pass. Missing is valid.

See `docs/catalog-backfill.md` and the P5-02 task file for the full workflow.
